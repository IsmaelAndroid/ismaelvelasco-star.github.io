# DI — Desarrollo de Interfaces

Bienvenid@ al temario de **Desarrollo de Interfaces** del ciclo **Desarrollo de Aplicaciones Multiplataforma (2º DAM)**.

Este curso el módulo se imparte íntegramente con **Kotlin y Jetpack Compose**, siguiendo la estructura oficial del módulo 0488 (RD 405/2023): teoría, ejercicios graduados con solucionario y presentaciones.

## Unidades

| # | Unidad | Estado |
|---|--------|--------|
| 1 | Introducción a la confección de interfaces | ✅ Publicada |
| 2 | Clases y componentes | ✅ Publicada |
| 3 | Generación de interfaces con XML | ✅ Publicada |
| 4 | Creación de componentes propios | ✅ Publicada |
| 5 | Explotación de componentes (eventos, estado, pruebas) | ✅ Publicada |
| 6 | Usabilidad y accesibilidad (WCAG, contraste, toques, pruebas) | ✅ Publicada |
| 7 | Interfaces naturales (voz, sensores, ML Kit y realidad aumentada) | ✅ Publicada |
| 8 | Informes: filtros, totales, gráficos y exportación a PDF y CSV | ✅ Publicada |
| 9 | Documentación y ayudas: ayuda contextual, esquema de datos y manual generado | ✅ Publicada |
| 10 | Distribución y publicación: variantes, firma, APK y bundle, canales | ✅ Publicada |
| 11 | Pruebas: estrategia, unitarias e integración, regresión, volumen, estrés, seguridad y recursos | ✅ Publicada |
