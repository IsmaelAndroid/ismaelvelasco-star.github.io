# UD 1 — GitHub: repositorios, versiones y trabajo en equipo

De la carpeta `final_final_v3` al historial profesional: commits, ramas, pull requests, issues y automatización con Actions. La base con la que trabajan todos los proyectos reales de software.

## Qué aprenderás

Al terminar la unidad serás capaz de: crear y clonar repositorios, entender el ciclo `add → commit → push`, leer el historial de un proyecto (`log`, `diff`, `blame`), trabajar con ramas sin miedo, abrir y revisar un pull request, reportar un bug en un issue y explicar qué hace un workflow de GitHub Actions.

## Evaluación (RA/CE)

Unidad anclada al **RA 2** del módulo 0484 (*"Evalúa entornos integrados de desarrollo..."*) y en particular al **CE 2.f** (*"Se ha realizado el control de versiones integrado en el entorno de desarrollo"*), que en este curso desarrollamos con Git + GitHub.
